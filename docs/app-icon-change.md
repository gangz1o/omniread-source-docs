# 网站 APP 图标统一

- 目标：所有文档页页头 Logo、浏览器 favicon，含 404 页 favicon。
- 问题：页头使用“云”字占位，favicon 使用自绘书本，与 APP 品牌不一致。
- 用户影响：网站与 APP 的识别形象不同。
- 参考：APP 默认 AppIcon 与 AppIconPreviewDefault 的浅色/深色资源。
- 验收：使用同一 APP 图标，正确跟随明暗模式，保留原有页头尺寸，图标不变形；资源和公网部署可访问。
- 范围：网站模板、品牌图片样式、两份 PNG 资源。
- 非目标：调整导航、文档内容、品牌颜色、APP 代码或其他布局。
- 行为保持：Logo 返回首页，文档跳转及下载行为不变。
- 共享影响：网站所有文档页页头和图标声明；iOS 设计令牌不受影响。
- 适配：浅色/深色图标、桌面 34px/紧凑宽度 30px，明确图片尺寸避免加载位移。图片 alt 为空以免重复朗读相邻“云书阁”。
- 不适用：动态数据空态/错误重试/编辑禁用状态、阅读器 Dynamic Type、Reduce Motion（无动效变化）。
- 实施：直接复制 APP 已有 240px 预览 PNG，保持图像不变；沿用网站既有尺寸与圆角，仅移除文字占位样式。
- 验证：构建、站内链接检查、来源字节一致性、图标声明及公网资源检查。
- 回退：还原本次网站提交即可；没有持久化数据迁移。
